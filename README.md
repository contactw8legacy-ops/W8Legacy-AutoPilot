## 🚀 What is W8Legacy AutoPilot?
**W8Legacy AutoPilot** is a high-performance C# console automation pipeline built specifically for faceless automotive content creators. Give it any car model, tuning project, or technical failure, and the engine takes full control:
1. **AI Scriptwriting:** Generates raw, anti-cliché scripts using Google Gemini (avoiding robotic intros and corporate advice).
2. **Smart B-Roll Scraper:** Extracts tailored visual search queries and downloads up to 10 real-world clips via yt-dlp.
3. **Dynamic Slicing & Subtitles:** Shuffles footage cuts at 30 FPS via FFmpeg and burns bold, yellow Impact subtitles synchronized to speech pauses.
4. **Auto-Scheduling:** Renders dual outputs and schedules them directly to YouTube Shorts & TikTok as *Private* to dodge spam flags.
