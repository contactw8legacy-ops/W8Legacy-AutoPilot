# 🏎️ W8Legacy AutoPilot — AI Automotive Shorts and TikTok Engine


**W8Legacy AutoPilot** is an end-to-end C# console automation engine built for faceless automotive content creators. Give it a car model or a mechanical issue, and it autonomously writes scripts, generates neural voiceovers, scrapes B-Roll, and schedules videos to YouTube Shorts and TikTok.
